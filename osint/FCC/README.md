# FCC (Federal Communications Commissions)

This challenge introduces players on how to perform OSINT on IoT/embedded devices (eg. routers). This is somewhat an OSINT/IoT challenge.

## Description

You are a cybersecurity student looking to learn more about IoT (Internet-of-Things) security testing (hacking). IoT refers to devices connected to the internet such as: routers, IP cameras, smart fridges, or even your mobile phones.

A good first step in IoT security research is to perform Open-Source Intelligence (OSINT) by gathering information about the target device through publicly available data found on the internet. This is useful to understand more about the target, even before you get your hands on the physical device. A common resource would be the Federal Communications Commission (FCC) pages: an agency that provides useful information about IoT devices

You recently found out that the Linksys E1200 v2 wireless router contains multiple unpatched vulnerabilities/security flaws. You found a fellow researcher named `jarrettgxz` who performed extensive research on this router model, and has published his work on various platforms.

Your goal for this challenge will be to perform OSINT on this router model, along with the related work this researcher have published. Refer to the `README.pdf` file provided to gather all the required portions to craft the final flag!

Remember, all the information you need can be found online!
