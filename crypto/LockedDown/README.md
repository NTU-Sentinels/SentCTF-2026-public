# LockedDown

### Author: Rushaidy

Following a ransomware attack, the school's archive server automatically enters Lockdown Mode, sealing the archive room. 

The emergency exit can only be unlocked using a digital access token generated by the server. Before the system went offline, several files were recovered from different rooms within the archive. 

As part of the incident response team, participants must investigate the environment, collect the available evidence, recover the emergency access token, and unlock the exit.

Flag format: `sentctf{...}` <br>
