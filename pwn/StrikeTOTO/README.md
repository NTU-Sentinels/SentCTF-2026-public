# Strike TOTO

### Author: Rushaidy
The school is hosting a lucky draw event where participants can win an exclusive grand prize. A legacy lucky draw application generates a random number each time a participant enters their name. Rumour has it that only one winning number unlocks the prize, but no one has ever managed to obtain it legitimately.

As part of the competition, participants are given a copy of the application to investigate whether the system is truly as random as it claims.



Flag format: `sentctf{...}` <br>
